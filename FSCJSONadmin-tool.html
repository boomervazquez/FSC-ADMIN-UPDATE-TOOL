How to Update the FSC Website

  1. Choose "Add New Entry" to create a single new FSC update, or "Full JSON Manager" to view/edit the complete dataset.
  2. Fill in the effective date, cadence (monthly or weekly), and each region's FSC percentage.
  3. Click "Generate JSON" to produce the formatted data.
  4. Copy the generated JSON output.
  5. Go to your JSONBin dashboard and paste (replace) the full JSON content.
  6. The website will automatically display the updated data on next page load.
